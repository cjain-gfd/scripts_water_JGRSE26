# Plotting scripts and animations for Jain & Sobolev (2026b, JGR: Solid Earth)
Plotting scripts and animations for Jain &amp; Sobolev (2026), Controls on the tectonic evolution of the early Earth: 2. Contrasted effects of water. Journal of Geophysical Research: Solid Earth

# Repository structure
    .
    ├── /data                           # Simulation data files, to be downloaded
    ├── /figures                        # Figures
    ├── /scripts                        # Plotting scripts
    ├── /animations                     # Animations for reference models
    ├── LICENSE                         # License agreement
    └── README.md                       # This README file

# Simulation data

In order to execute the plotting scripts, please download *data_and_scripts.zip* from [https://doi.org/10.5281/zenodo.22734907](https://doi.org/10.5281/zenodo.22734907) and unzip it in */data/*. Plotting scripts only work when this simulation data set is present in the data folder.

# Software requirements

Python 3.x, see the individual plotting scripts for the required packages.
